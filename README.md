# GMM Maintenance Management System

A web-based maintenance management system developed using SQL Server and Python/Flask.

## About the Project

This project was developed to enable systematic, traceable, and data-driven management of machine maintenance activities.

The system focuses on machine criticality assessment, failure risk evaluation, maintenance planning, and maintenance activity tracking.

## Methodologies

- **AHP (Analytic Hierarchy Process):** Machine criticality assessment
- **FMEA (Failure Mode and Effects Analysis):** Failure risk assessment
- **KPI & Dashboard:** Visual monitoring of maintenance performance

## System Modules

- Machine Management
- Machine Criticality Analysis
- Maintenance Planning
- Maintenance Records
- Work Orders
- Spare Parts Management
- Dashboard & KPIs
- Reporting

## Technologies

- Python
- Flask
- SQL Server
- HTML
- CSS
- JavaScript
- Chart.js

## Project Outcome

The developed system provides a centralized structure for monitoring maintenance plans and activities, identifying critical machines and maintenance priorities, and creating a foundation for future analysis of maintenance data.

> **Note:** This GitHub repository contains a public demo version of the project. Real company data and SQL Server connection credentials are not included.
